# 1.6.3

- Das Rabatt-Badge in Produktlisten und Slidern wird ausgeblendet, solange Preise versteckt sind, auch Rabatt-Badges anderer Erweiterungen, die im Badge-Block des Cores rendern. Die Badges "Neu" und "Topseller" bleiben.
- Produktdetailseiten waren bereits abgedeckt: Der Preisblock samt Rabatt-Badge wird nicht gerendert, solange Preise versteckt sind.

# 1.6.2

- Die README beschreibt das Request-Attribut `hidePrice`, damit andere Erweiterungen, die Preise in eigenen Templates ausgeben, es beachten können.
- Sicherheitsrichtlinie ergänzt und dokumentiert, dass die Store API nicht abgedeckt ist.
- Getestet mit Shopware 6.7.16.0.
- Changelog auf Englisch und Deutsch ergänzt.
