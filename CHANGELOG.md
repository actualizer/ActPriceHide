# 1.6.3

- The discount badge in product listings and sliders is hidden while prices are hidden, including discount badges of other extensions that render inside the core badge block. The new and topseller badges stay.
- Product detail pages were already covered: the price block, including its discount badge, is not rendered while prices are hidden.

# 1.6.2

- The README documents the `hidePrice` request attribute, so other extensions that render prices from their own templates can respect it.
- Added a security policy and documented that the Store API is not covered.
- Tested with Shopware 6.7.16.0.
- Added a changelog in English and German.

Earlier versions: see the [tags on GitHub](https://github.com/actualizer/ActPriceHide/tags).
